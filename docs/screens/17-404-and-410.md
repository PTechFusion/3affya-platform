# 17. 404 and 410

**Area:** Public · **Purpose:** Missing or removed pages · **Build:** M2 · **Task:** 2.2 · **In prototype (23 Oct):** Yes

**Notes:** 410 for removed doctors

## States to design

- 404
- 410 removed profile

## Data shown

Message, search box

## Layout call (phone first)

Centred: short message, search box, four specialty chips, contact link. 410 adds one line that the doctor asked to be removed. Above the fold: everything.

## Pointers

- Search box plus popular specialties and a contact path; 410 explains the doctor was removed at their request and offers the specialty search. `[S6 L4]`

## Rules referenced

- **L4** (research) Errors: exact problem next to the element, the fix, input preserved, no blame, no humour, no codes by default. _Evidence: NN/g error-message guidelines; WCAG 3.3.1._ Source: NN/g Error-Message Guidelines <https://www.nngroup.com/articles/error-message-guidelines/>
- **S6** (research) Zero results must offer: relaxed-filter parent scope, 3 to 5 alternative queries with previews (auto-applied if only one works), popular doctors, and a human contact. _Evidence: About half of no-results pages raise abandonment; spelling tips alone are not enough._ Source: Baymard, No Results Page <https://baymard.com/research-articles/no-results-page>
